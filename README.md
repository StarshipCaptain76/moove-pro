# MOOVE - Reliable Transport & Removal Services

## Overview
MOOVE is a South African transport and removal company specializing in reliable logistics, furniture moving, and general cargo transport. Operating Toyota Dyna trucks and trailers for efficient service.

## Vehicle Specifications
- **Truck (DYNA 150 C/C)**: GMW 5300kg
  - Load bed: 3m x 2m x 0.4m
- **Trailer**: 3m x 2m x 0.85m

## Branding
- Logo features a stylized truck with red crescent accent.
- Fleet vehicles in white with prominent "MOOVE" branding.
